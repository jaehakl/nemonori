# 포켓몬 마블 데이터 출처

포켓몬 마블은 게임 실행 중 외부 API를 호출하지 않습니다. 기본 종 1,025종의
한국어·영어 이름, 타입, 종족값, 레벨업 기술표, 진화 정보와 기본 정면 스프라이트를
아래 고정 버전에서 가져왔습니다.

- 데이터: [PokéAPI/pokeapi](https://github.com/PokeAPI/pokeapi/tree/bc92d3b6029ef1abe9e7ad424c400b338f3c11fe), `bc92d3b6029ef1abe9e7ad424c400b338f3c11fe`
- 이미지: [PokéAPI/sprites](https://github.com/PokeAPI/sprites/tree/bfb75391935310368065096fa08c51e8970bc43e), `bfb75391935310368065096fa08c51e8970bc43e`
- 데이터 라이선스 원문: [POKEAPI-LICENSE.txt](./POKEAPI-LICENSE.txt)
- 기술 효과 대조: [Pokémon Showdown](https://github.com/smogon/pokemon-showdown/tree/9fb3a5b99f1a0bea17f495c5cc1bfe04fdd19c3e/data), `9fb3a5b99f1a0bea17f495c5cc1bfe04fdd19c3e`
- 기술 효과 소스 라이선스: [POKEMON-SHOWDOWN-LICENSE.txt](./POKEMON-SHOWDOWN-LICENSE.txt) (MIT)

Pokémon과 Pokémon 캐릭터 이름은 Nintendo의 상표입니다. 스프라이트는 PokéAPI
저장소에서 배포하는 원본 파일을 수정하지 않고 사용합니다. 해당 저장소는
650번 이후 B&W 스타일 스프라이트에 기여한 Smogon 커뮤니티와 9세대 기본 정면
스프라이트를 제공한 KingOfThe-X-Roads에게 감사를 명시합니다. 자세한 이미지
출처는 위 스프라이트 저장소의 README를 참조하세요.

## 다시 가져오기

프로젝트 루트에서 Node.js 24 이상으로 실행합니다.

```sh
node scripts/import-pokemon-data.mjs
node --test tests/pokemon-data.test.mjs
```

가져오기 도구는 고정 커밋의 CSV, PNG와 기술 효과 소스를 다운로드합니다. 소스는 AST로
리터럴만 읽으며 다운로드한 코드를 실행하지 않습니다. 내려받은 원본은 운영체제의
임시 폴더 `nemonori-pokemon-import`에 커밋별로 캐시합니다. 생성물은
`app/games/_components/pokemon-marble/generated/catalog.ts`와 현재 폴더의
`sprites/`에 저장합니다. 원본 CSV·기술 효과 소스·라이선스, 최종 카탈로그, 1,025개 PNG의 SHA-256 해시는
`generated/provenance.json`에 기록되며 테스트에서 생성물의 무결성을 확인합니다.
이미 로컬에 이미지가 있다면 `--reuse-sprites`로 재다운로드를 생략할 수 있습니다.

## 게임용 변환

- 도감 번호 1~1,025의 기본 포켓몬만 사용합니다. 리전폼과 메가진화 등 별도 폼은 제외합니다.
- 종마다 레벨업 기록이 존재하는 가장 최근 버전 그룹의 기술표를 사용합니다. 위력이 양수인
  물리·특수 공격만 남기며 중복 기술의 습득 레벨은 가장 낮은 값을 사용합니다.
- 초기 기술과 야생의 기술은 보유 레벨 이하 학습표를 습득 레벨순, 같은 레벨이면 기술 ID순으로
  정렬한 최신 네 개로 구성합니다. 야생은 출현할 최종 진화종의 학습표를 사용합니다.
  이후 레벨업·진화로 새 기술을 배우면 자동으로 빈 슬롯에 추가하고, 네 칸이 찼으면 가장
  오래된 기술부터 잊습니다. 이미 아는 기술은 중복 습득하지 않으며 기술 선택창은 띄우지 않습니다.
  사용 가능한 기술이 없을 때만 발버둥을 제공합니다.
- 일반 레벨업 진화의 요구 레벨은 유지하고 돌·교환·친밀도·시간 등 추가 조건은 레벨 20으로
  대체합니다. 가장 최근의 기본 진화 조건과 종 단위 진화 관계를 사용합니다.
- 별도 리전폼을 생성하지 않으므로 나이킹·마임꽁꽁 등 리전폼에서만 이어지는 새로운 종도
  해당 기본 종에서 진화할 수 있습니다. 이때 단순 레벨 조건은 원래 레벨을 유지합니다.
- 야생은 기본종의 희귀도 범주로 추첨한 뒤 1~파티 최고 레벨에서 레벨을 균등 추첨합니다.
  파티의 행동불능 포켓몬은 포함하고 박스·도로 수비는 제외합니다. 진화 레벨을 충족하면
  가능한 단계까지 진화한 상태로 출현하며 분기 후보는 균등 추첨합니다.
- 기존 공격기 431개와 발버둥을 수록합니다. 변화기나 새 학습 기술은 추가하지 않습니다.
  카타스트로피·앙갚음의 원본 자리표시자 위력 1은 각각 현재 HP의 절반·받은 피해의 1.5배로 처리합니다.
- 명중률·급소·흡수·반동·연속 타격·상태·능력치 변화는 선언형 효과이며,
  HP·사용 이력에 따른 위력, 충전·휴식, 고정·지연 피해 등은 이름 있는 개별 규칙으로 처리합니다.
  PokéAPI `move_meta` 및 `move_meta_stat_changes`를 가져오고 고정 Showdown 소스와 대조합니다.
  분류되지 않은 콜백·필드는 가져오기를 실패시키며 평범한 공격으로 조용히 대체하지 않습니다.
- 각 기술은 `full`(지원), `base`(지원하지 않는 별도 시스템의 효과만 생략),
  `excluded`(필수 조건을 지원하지 않아 편성 제외)로 분류합니다. 제외·생략 이유도 저장합니다.
  도구·날씨·필드·교체·별도 폼·특성은 도입하지 않습니다. 기습·질풍신뢰처럼
  상대의 아직 선택하지 않은 기술이 필요한 공격은 제외합니다. 피격 반격은 직전 상대 행동을 기준으로 합니다.
- 피해 공식의 레벨 계수·공격/방어·자속·상성과 버림 순서를 유지하며 무작위 피해 편차는 없습니다.
  급소는 기본 1/24, 1.5배이며 불리한 공격 단계와 유리한 방어 단계를 무시합니다.
  흡수·피해 비례 반동은 실제 감소 HP를 기준으로 반올림하고, 발버둥은 최대 HP의 1/4을 반올림합니다.
- 수비 측 선공 후 번갈아 행동하며, 양쪽 행동 기회 한 번이 한 라운드입니다.
  충전·휴식·강제 연속 사용도 행동을 소비합니다. 지속 피해는 라운드 끝에 처리합니다.
  상태·능력치 변화는 배틀 종료 시 해제하고 HP는 유지합니다. PP·우선도에 따른 순서 변경은 없습니다.
